!!! summary "이 수업은"
    2018년 2학기에 들은 대학교 수업이다. 공기나 기름의 압력으로 힘을 내는 공압·유압 기기의 원리와, 밸브와 실린더로 회로를 꾸며 정해진 순서대로 움직이게 하는 제어 기법을 배웠다. 이후 [PLC실습](01-plc.md)에서 같은 공압 회로를 PLC 프로그램으로 제어하는 바탕이 됐다.

## 공압과 유압

| | 공압 | 유압 |
|---|---|---|
| 매체 | 압축 공기 | 기름(작동유) |
| 힘 | 작음 | 큼 |
| 속도 | 빠름 | 상대적으로 느림 |
| 특징 | 깨끗하고 값싸며 다루기 쉽다. 공기가 압축되므로 정밀한 위치·속도 제어는 어렵다 | 기름이 거의 압축되지 않아 큰 힘을 정밀하게 낼 수 있다. 누유와 온도 관리가 필요하다 |

밀폐된 유체에 가한 압력은 모든 방향으로 똑같이 전달된다(**파스칼의 원리**). 그래서 실린더의 힘은 압력 × 피스톤 면적이고, 같은 압력이라도 면적이 큰 실린더가 더 큰 힘을 낸다.

## 주요 기기

| 기기 | 역할 |
|---|---|
| 압축기, 펌프 | 공기를 압축하거나(공압) 기름을 밀어 보내(유압) 압력을 만든다 |
| 공기 조정 유닛 | 필터(먼지·수분 제거), 레귤레이터(압력 조절), 루브리케이터(윤활)를 묶은 장치 |
| 릴리프 밸브 | 압력이 설정값을 넘으면 열려 회로를 보호한다 |
| 실린더 | 압력을 직선 운동으로 바꾼다. 한쪽만 공기로 밀고 스프링으로 돌아오는 **단동**, 양쪽 모두 공기로 밀고 당기는 **복동** |
| 방향 제어 밸브 | 유체가 흐르는 길을 바꿔 실린더를 전진·후진시킨다. 포트 수와 위치 수로 3/2, 5/2 밸브처럼 부른다 |
| 유량 제어 밸브 | 흐르는 양을 줄여 실린더 속도를 조절한다 |
| 체크 밸브 | 한 방향으로만 흐르게 한다 |

## 제어 기법

- **속도 제어:** 실린더로 들어가는 쪽(미터인)이나 나오는 쪽(미터아웃)의 유량을 줄여 속도를 조절한다. 공압에서는 나오는 쪽을 조이는 미터아웃이 부하가 바뀌어도 속도가 덜 흔들린다.
- **논리 회로:** 두 입력이 모두 있어야 출력이 나오는 AND(2압 밸브), 둘 중 하나만 있어도 나오는 OR(셔틀 밸브)처럼 밸브로 논리를 만든다. 양손으로 두 버튼을 동시에 눌러야 움직이는 안전 회로가 AND의 예다.
- **전기 공압:** 밸브를 솔레노이드(전자석)로 움직이고, 버튼·리밋 스위치·센서와 릴레이로 회로를 꾸며 전기 신호로 제어한다. 실린더가 끝까지 갔는지는 리밋 스위치나 실린더 센서로 확인한다.
- **순차 제어:** 여러 실린더를 정해진 순서대로 움직인다. 순서는 A+ B+ A− B−(A 전진 → B 전진 → A 후진 → B 후진)처럼 적고, 실린더 위치를 단계별로 그린 **변위-단계 선도**로 설계한다. 앞 동작이 끝났다는 신호가 들어와야 다음 동작을 시작하게 하는 것이 기본이다.
