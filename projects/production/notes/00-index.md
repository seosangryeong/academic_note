## 생산관리란

생산관리(운영관리)는 원자재, 설비, 노동력, 에너지 같은 **투입물**을 일정한 **프로세스**로 바꿔 제품이나 서비스라는 **산출물**을 만드는 과정을 관리하는 일이다. 목표는 이 변환 과정의 부가가치, 즉 생산성을 높이는 것이다. 시스템을 설계(계획)하고, 실행하고, 결과를 계획과 비교해 다음 계획에 반영하는 과정을 반복한다. 제조업뿐 아니라 병원, 항공사, 식당, 대학 같은 서비스업에도 똑같이 적용된다.

| | 제품 (제조업) | 서비스 (서비스업) |
|---|---|---|
| 산출물 | 유형, 보관 가능 | 무형, 시간이 지나면 사라짐 |
| 재고 | 쌓아 둘 수 있음 | 쌓아 둘 수 없음 → 수요예측이 더 중요 |
| 생산과 소비 | 생산이 먼저, 장소도 분리 가능 | 동시에 같은 곳에서 일어남 |
| 고객 접촉 | 간접적 | 대부분 직접 |
| 품질 평가 | 객관적이고 쉬움 | 주관적이고 어려움 |
| 집약도 | 자본 집약적 | 노동 집약적 |

**생산성 = 산출량 ÷ 투입량**이다. 노동생산성은 부가가치 ÷ 종업원 수, 조업도(가동률)는 실제 생산량 ÷ 표준 생산량으로 잰다.

## 생산관리의 역사

| 시기 | 흐름 |
|---|---|
| 18세기 후반 | 1차 산업혁명으로 가내 수공업이 공장제 공업으로 바뀜. 애덤 스미스는 『국부론』에서 일을 작은 과업으로 나누는 **분업**을 제시 |
| 1911 | 테일러의 **과학적 관리법**: 시간 연구와 동작 연구로 작업을 측정해 최선의 방법을 표준화하고 하루 표준 작업량과 성과급을 정함. 인간적 요소를 소홀히 했다는 비판 |
| 1910년대 | 포드의 **대량생산**: 부품 표준화(호환성), 제품 단순화, 작업 세분화, 컨베이어 이동 조립. 대신 다양한 수요에 대응하기 어렵고 공정 병목과 비인간화 문제 |
| 1930년대 | **호손 실험**: 조명이나 휴식 같은 물리적 조건보다 인간관계, 소속감, 사기가 성과에 더 큰 영향을 줌 |
| 1980년대 | 일본식 생산관리(적시생산 JIT, 전사적 품질경영 TQM)가 주목받음. CAD/CAM, CNC, FMS(유연 생산 시스템), 6시그마 |
| 1990–2000년대 | 회사 업무를 하나로 묶는 **ERP**, 원자재부터 고객까지 공급망 전체를 관리하는 **SCM** |
| 최근 | 서비스 부문 성장, 글로벌 경쟁, 다품종 소량 생산을 낮은 원가로 하는 **대량 고객화**, 환경·안전을 고려한 지속가능 경영과 탄소 중립 |

## 경쟁우선순위

기업이 경쟁에서 무엇을 무기로 삼을지 정한 것이다. 생산관리 관점에서는 다섯 가지를 본다.

| 우선순위 | 내용 |
|---|---|
| 원가 | 재료비, 노무비, 불량 손실 등 단위당 원가를 낮춤. 규모의 경제, 핵심 역량 외 아웃소싱 |
| 품질 | 고객이 기대한 대로, 설계 규격대로 만듦. 가장 강력한 차별화 요소 |
| 시간 | 주문부터 인도까지의 리드 타임 단축, 납기 준수, 개발 속도 |
| 유연성 | 수요 변동에 맞춰 생산량을 빨리 바꾸고, 여러 제품을 한 라인에서 만드는 능력. 준비 시간 단축, FMS, 산업용 로봇, 스마트 팩토리 |
| 서비스 | 판매 전후 지원 등 |

우선순위끼리는 서로 부딪힌다. 원가를 낮추면 유연성이 떨어지고, 품질을 높이면 원가가 오른다. 같은 자동차 회사라도 저가 대량 생산 회사는 원가와 일관된 품질, 빠른 인도를, 고가 주문형 스포츠카 회사는 품질을 가장 앞에 둔다.

## 수요예측

제품과 서비스의 수요가 **언제, 얼마나** 생길지 예측하는 일이다. 이 예측을 바탕으로 자재, 설비, 인력 계획이 정해지므로, 과잉 생산과 재고 고갈을 막는 출발점이다.

- **기간:** 단기(6개월 이내, 일정계획·생산 수량), 중기(6개월–2년, 총괄계획·인력·자재 계획), 장기(2년 이상, 공장 입지·설비 투자)
- **예측의 특성:** 과거의 경향이 미래에도 이어진다고 가정한다. 완벽한 예측은 없다. 개별 품목보다 제품군 전체의 예측이 더 정확하다. 먼 미래일수록 정확도가 떨어진다.

### 정성적 기법

과거 데이터가 없거나 믿기 어려울 때, 사람의 경험과 판단으로 예측한다. 주로 중·장기 예측에 쓴다.

| 기법 | 방법 |
|---|---|
| 시장 조사 | 설문, 면접 등으로 소비자에게 직접 묻는다. 정성적 기법 중 가장 객관적이지만 시간과 비용이 많이 든다 |
| 판매원 의견 합성 | 판매원들이 담당 지역 수요를 예측해 합친다. 싸고 빠르지만 판매 목표가 걸리면 일부러 낮게 예측하기 쉽다 |
| 중역 의견 | 경영진이 모여 예측한다. 빠르지만 목소리 큰 사람에게 끌려갈 수 있다 |
| 델파이법 | 서로 누군지 모르는 전문가들에게 설문하고, 결과를 통계로 다시 보여 주며 의견이 모일 때까지 반복한다. 장기·기술 예측에 맞다 |
| 패널 동의 | 소비자, 영업사원, 경영자로 패널을 꾸려 의견을 모은다 |
| 역사적 유추 | 비슷한 기존 제품의 수명주기 수요 변화를 보고 신제품 수요를 유추한다 |

### 시계열 기법

과거 수요 기록에서 패턴을 찾아 미래로 늘린다. 주로 단기·중기 예측과 일정계획, 재고관리에 쓴다. 수요는 **추세**(장기 경향), **순환**(1년 이상의 불규칙한 주기), **계절**(1년 주기), **불규칙**(우연) 변동으로 나눠 본다. 이를 더해서 보는 가법 모델(Y = T + C + S + I)과 곱해서 보는 승법 모델(Y = T × C × S × I)이 있다.

| 기법 | 식 | 특징 |
|---|---|---|
| 단순이동평균 | F<sub>t</sub> = (최근 n기 실제 수요의 합) ÷ n | n이 크면 안정적이지만 변화에 늦게 반응하고, 작으면 빨리 반응하지만 우연 변동에 흔들린다 |
| 가중이동평균 | F<sub>t</sub> = Σ w<sub>i</sub>A<sub>t−i</sub> ÷ Σ w<sub>i</sub> (최근일수록 큰 가중치) | 최근 변화를 더 많이 반영 |
| 지수평활 | F<sub>t+1</sub> = αA<sub>t</sub> + (1 − α)F<sub>t</sub> | 직전 예측치와 실제값만 있으면 된다. α가 크면(0.7–0.8) 변화에 민감해 신제품처럼 수요가 불안정할 때, 작으면(0.1–0.3) 수요가 안정적일 때 쓴다. 추세가 강한 자료에는 맞지 않는다 |

### 인과형 기법

수요에 영향을 주는 원인 변수와의 관계로 예측한다. 주로 중·장기 예측에 쓴다. 대표적인 **회귀분석**은 독립변수(원인)와 종속변수(수요)의 관계를 y = a + bx 같은 식으로 놓고, 최소자승법으로 a와 b를 구한다. 상관계수 r은 두 변수가 얼마나 함께 움직이는지, 결정계수 r²은 수요 변동 중 독립변수로 설명되는 비율을 나타낸다.

| 용도 | 기간 | 맞는 기법 |
|---|---|---|
| 공정 설계, 설비 계획 | 장기 | 정성적 기법, 인과형 |
| 총괄계획 | 중기 | 인과형, 시계열 |
| 일정계획, 재고관리 | 단기 | 시계열 |

## 제품 설계 및 개발

제품 원가와 품질의 60–80%가 설계 단계에서 정해지기 때문에, 설계 때부터 마케팅과 생산 부서가 함께 봐야 한다.

- **신제품 도입 전략:** 고객 요구에서 출발하는 **시장 지향**(market-pull), 기술에서 출발하는 **기술 지향**(technology-push), 두 가지를 모든 부서가 함께 조율하는 **기능 간 협력**(현재 가장 많이 씀)
- **제품 수명주기:** 도입기(경쟁자 적음, 설계 변경 잦음) → 성장기(판매 급증, 정확한 수요예측이 중요) → 성숙기(경쟁 격화, 원가와 표준화가 핵심) → 쇠퇴기(대체품 등장, 매출 급감)
- **설계 과정:** 아이디어 → 타당성 평가 → 예비 설계 → 원형 제작·시험 → 상세 설계(기능·형태·생산 설계) → 생산
- **제조물 책임:** 제품 결함(설계·제조·경고상의 결함)으로 생긴 손해를 생산·유통·판매에 관여한 자가 배상할 책임

### 설계 기법

| 기법 | 내용 |
|---|---|
| 동시공학 | 설계, 생산, 품질, 마케팅 담당자가 처음부터 한 팀으로 순서를 겹쳐 진행해 개발 기간을 줄인다 |
| 제조 용이성 설계 (DFM/DFMA) | 부품 수를 줄이고, 위에서 아래로 조립하고, 손 움직임을 줄이는 등 만들고 조립하기 쉽게 설계 |
| 단순화 | 부품과 옵션 수를 줄인다(예: 볼트 조립 대신 끼워 넣는 방식). 조립 시간과 재고가 줄고 품질이 오른다 |
| 표준화 | 부품의 크기, 모양, 성능을 규격으로 정해 여러 제품에 같이 쓴다 |
| 모듈화 | 여러 제품에 쓰는 표준 중간 조립품(모듈)을 만든다. 엔진 4종, 변속기 2종, 외부 색상 5종, 내부 사양 2종이면 모듈 13가지로 제품 80가지를 만든다 |
| 친환경 설계 | 재활용, 분해, 환경 영향을 고려한 설계. ISO 14000, 탄소 중립 |
| 강건 설계 | 제조와 사용 환경이 바뀌어도 성능이 덜 흔들리도록, 실험으로 가장 둔감한 설계값을 찾는다 |
| 가치공학 (VE) | 가치 = 기능 ÷ 비용. 필요한 기능은 유지하면서 가치에 기여하지 않는 비용을 설계 단계에서 없앤다. 이미 생산 중인 제품에 적용하면 가치분석(VA) |
| CAD / CAM / CAE | 컴퓨터로 설계(무엇을), 가공 데이터 생성(어떻게), 해석과 검증(왜)을 한다 |

## 입지부터 품질관리까지

| 주제 | 내용 |
|---|---|
| 입지 선택 | 시장과 원자재까지의 거리, 운송비, 인건비, 인프라 등을 따져 공장이나 서비스 시설의 위치를 정한다 |
| 용량 설계 | 수요예측을 바탕으로 설비가 감당할 생산능력의 크기와 확장 시점을 정한다 |
| 프로세스 분석 및 설비 배치 | 제품과 수량에 맞는 공정 형태를 고르고, 설비와 작업장을 흐름에 맞게 배치한다(제품별, 공정별, 고정 위치 배치 등) |
| 총괄생산계획 | 중기 수요에 맞춰 제품군 단위로 생산량, 인력, 재고 수준을 정한다 |
| 일정계획 | 정해진 계획을 기계와 작업 단위의 구체적인 순서와 시점으로 나눈다 |
| 품질관리 | 규격에 맞는 제품을 만들도록 공정을 관리하고, 통계적 방법으로 불량을 줄인다 |
