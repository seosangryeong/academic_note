!!! summary "이 수업에서"
    2024년 1학기 '딥러닝'과 2학기 '고급 딥러닝'을 이어서 들었다. 앞 학기에는 RNN과 VAE처럼 기본이 되는 모델을, 뒤 학기에는 그래프 신경망과 **생성 모델**(에너지 기반 모델, 정규화 흐름, 확산 모델)을 중심으로 배웠다. 주제마다 PyTorch 실습 코드가 같이 있었다.

## 배운 것

### 순서가 있는 데이터: RNN과 LSTM

RNN은 이전 시점의 은닉 상태를 다음 시점에 다시 넣어 순서를 기억한다. 시간 축으로 펼치면 깊은 네트워크가 되어 역전파(BPTT) 중에 기울기가 사라지거나 폭발한다. **LSTM**은 게이트로 무엇을 기억하고 잊을지 정해 이 문제를 줄인다. 문자 단위 언어 모델, 이미지 캡셔닝, MNIST를 한 줄씩 읽어 분류하기, Seq2Seq 번역 구조를 다뤘다. Seq2Seq는 입력 전체를 고정 길이 벡터 하나에 담아야 하는 병목이 있다.

### 학습과 최적화

손실 함수는 문제에 맞게 고른다. 회귀는 L2, 분류는 교차 엔트로피나 Focal loss, 비슷한 것끼리 가깝게 만드는 유사도 학습은 순위 기반 손실을 쓴다. 최적화는 SGD에 모멘텀을 더하거나 파라미터별로 학습률을 조절하는 RMSProp, Adam을 쓴다.

### 확률로 보는 딥러닝: MCMC

베이즈 정리로 사후분포를 구하려면 분모(증거)를 적분해야 하는데, 대부분 계산할 수 없다. 켤레 사전분포처럼 식으로 풀리는 경우는 드물다. **MCMC**는 사후분포를 직접 구하지 않고, 그 분포를 따르는 샘플을 만들어 근사한다. Metropolis-Hastings는 후보를 제안하고 확률 비율에 따라 받아들이거나 버리는 것을 반복한다. 이 샘플링 아이디어는 뒤의 에너지 기반 모델에서 다시 나온다.

### 그래프 신경망 (GCN)

이미지처럼 격자가 아닌, 노드와 연결로 된 데이터를 다룬다. 각 노드가 이웃 노드의 특징을 모아(인접 행렬 + 자기 자신, 차수로 정규화) 자기 특징을 갱신하는 것이 그래프 합성곱이다. PyTorch Geometric으로 Zachary 가라테 클럽의 노드 분류와 MUTAG 분자 그래프 분류를 실습했다.

### 생성 모델

생성 모델의 목표는 데이터 분포 p(x)를 배워서 새 샘플을 만드는 것이다. 고차원 데이터는 실제로는 낮은 차원의 구조(manifold) 위에 있어서, 낮은 차원의 **잠재 변수**로 표현하는 접근이 많다.

| 모델 | 아이디어 | 장단점 |
|---|---|---|
| VAE | 인코더가 입력을 잠재 분포로, 디코더가 다시 데이터로. 재구성 오차 + 잠재 분포와 정규분포 사이의 KL로 학습하고, 재매개변수화 트릭으로 샘플링을 미분 가능하게 만든다 | 안정적으로 학습되지만 결과가 흐릿한 편 |
| VQ-VAE | 잠재 공간을 연속값 대신 코드북의 이산 벡터로 둔다. 이산 토큰이라 언어 모델과 결합해 텍스트로 이미지를 만들 수 있다 | |
| 에너지 기반 모델 | 데이터일수록 낮은 에너지를 주는 함수를 배운다. 데이터의 에너지는 낮추고 모델이 만든 샘플의 에너지는 높이며 학습하고, Langevin MCMC로 샘플링한다 | 형태가 자유롭지만 샘플링이 느리다 |
| 정규화 흐름 | 단순한 분포를 역변환 가능한 함수들로 여러 번 바꿔 데이터 분포를 만든다. 변수 변환 공식으로 정확한 likelihood를 계산하고, coupling layer(Real-NVP)로 야코비안 계산을 쉽게 만든다 | 정확한 확률을 주지만 구조 제약이 크다 |
| 확산 모델 (DDPM) | 데이터에 노이즈를 조금씩 더하는 과정을 거꾸로 되돌리도록 배운다. 결국 **각 단계에서 더해진 노이즈를 예측**하는 단순한 학습이 된다 | 품질이 좋지만 샘플링 단계가 많아 느리다 |

확산 모델은 픽셀 대신 오토인코더의 잠재 공간에서 확산을 돌려 빠르게 만든 **Latent Diffusion(Stable Diffusion)**, 텍스트·레이아웃·클래스 조건으로 생성하는 방법, classifier-free guidance로 이어진다. 로봇 쪽에서는 확산 모델로 행동 궤적을 생성하는 **Diffusion Policy**가 나온다. 이미지 대신 로봇 동작을 생성 대상으로 보는 관점이라, 생성 모델이 로봇 제어로 이어지는 지점이다.
