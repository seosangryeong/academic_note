!!! summary "이 수업에서"
    2024년 1학기 '딥러닝'과 2학기 '고급 딥러닝'을 이어서 들었다. 앞 학기에는 RNN과 VAE처럼 기본이 되는 모델을, 뒤 학기에는 그래프 신경망과 **생성 모델**(에너지 기반 모델, 정규화 흐름, 확산 모델)을 중심으로 배웠다. 주제마다 PyTorch 실습 코드가 같이 있었고, 1학기 과제로 **포켓몬 150종 이미지 분류기**를 만들어 정규화·최적화·구조 기법을 하나씩 바꿔 가며 비교했다.

## 배운 것

### 순서가 있는 데이터: RNN과 LSTM

RNN은 이전 시점의 은닉 상태를 다음 시점에 다시 넣어 순서를 기억한다. 시간 축으로 펼치면 깊은 네트워크가 되어 역전파(BPTT) 중에 기울기가 사라지거나 폭발한다. **LSTM**은 게이트로 무엇을 기억하고 잊을지 정해 이 문제를 줄인다. 문자 단위 언어 모델, 이미지 캡셔닝, MNIST를 한 줄씩 읽어 분류하기, Seq2Seq 번역 구조를 다뤘다. Seq2Seq는 입력 전체를 고정 길이 벡터 하나에 담아야 하는 병목이 있다.

### 학습과 최적화

손실 함수는 문제에 맞게 고른다. 회귀는 L2, 분류는 교차 엔트로피나 Focal loss, 비슷한 것끼리 가깝게 만드는 유사도 학습은 순위 기반 손실을 쓴다. 최적화는 SGD에 모멘텀을 더하거나 파라미터별로 학습률을 조절하는 RMSProp, Adam을 쓴다.

### 확률로 보는 딥러닝: MCMC

베이즈 정리로 사후분포를 구하려면 분모(증거)를 적분해야 하는데, 대부분 계산할 수 없다. 켤레 사전분포처럼 식으로 풀리는 경우는 드물다. **MCMC**는 사후분포를 직접 구하지 않고, 그 분포를 따르는 샘플을 만들어 근사한다. Metropolis-Hastings는 후보를 제안하고 확률 비율에 따라 받아들이거나 버리는 것을 반복한다. 이 샘플링 아이디어는 뒤의 에너지 기반 모델에서 다시 나온다.

### 그래프 신경망 (GCN)

이미지처럼 격자가 아닌, 노드와 연결로 된 데이터를 다룬다. 각 노드가 이웃 노드의 특징을 모아(인접 행렬 + 자기 자신, 차수로 정규화) 자기 특징을 갱신하는 것이 그래프 합성곱이다. PyTorch Geometric으로 Zachary 가라테 클럽의 노드 분류와 MUTAG 분자 그래프 분류를 실습했다.

### 생성 모델

생성 모델의 목표는 데이터 분포 p(x)를 배워서 새 샘플을 만드는 것이다. 고차원 데이터는 실제로는 낮은 차원의 구조(manifold) 위에 있어서, 낮은 차원의 **잠재 변수**로 표현하는 접근이 많다.

| 모델 | 아이디어 | 장단점 |
|---|---|---|
| VAE | 인코더가 입력을 잠재 분포로, 디코더가 다시 데이터로. 재구성 오차 + 잠재 분포와 정규분포 사이의 KL로 학습하고, 재매개변수화 트릭으로 샘플링을 미분 가능하게 만든다 | 안정적으로 학습되지만 결과가 흐릿한 편 |
| VQ-VAE | 잠재 공간을 연속값 대신 코드북의 이산 벡터로 둔다. 이산 토큰이라 언어 모델과 결합해 텍스트로 이미지를 만들 수 있다 | |
| 에너지 기반 모델 | 데이터일수록 낮은 에너지를 주는 함수를 배운다. 데이터의 에너지는 낮추고 모델이 만든 샘플의 에너지는 높이며 학습하고, Langevin MCMC로 샘플링한다 | 형태가 자유롭지만 샘플링이 느리다 |
| 정규화 흐름 | 단순한 분포를 역변환 가능한 함수들로 여러 번 바꿔 데이터 분포를 만든다. 변수 변환 공식으로 정확한 likelihood를 계산하고, coupling layer(Real-NVP)로 야코비안 계산을 쉽게 만든다 | 정확한 확률을 주지만 구조 제약이 크다 |
| 확산 모델 (DDPM) | 데이터에 노이즈를 조금씩 더하는 과정을 거꾸로 되돌리도록 배운다. 결국 **각 단계에서 더해진 노이즈를 예측**하는 단순한 학습이 된다 | 품질이 좋지만 샘플링 단계가 많아 느리다 |

확산 모델은 픽셀 대신 오토인코더의 잠재 공간에서 확산을 돌려 빠르게 만든 **Latent Diffusion(Stable Diffusion)**, 텍스트·레이아웃·클래스 조건으로 생성하는 방법, classifier-free guidance로 이어진다. 로봇 쪽에서는 확산 모델로 행동 궤적을 생성하는 **Diffusion Policy**가 나온다. 이미지 대신 로봇 동작을 생성 대상으로 보는 관점이라, 생성 모델이 로봇 제어로 이어지는 지점이다.

## 과제: 포켓몬 150종 이미지 분류 (2024년 1학기)

Kaggle의 포켓몬 이미지 데이터셋(150종)으로 분류 모델을 만들었다. 간단한 기본 모델(Model_0)을 먼저 만들고, 과제마다 **기법 하나만 바꿔서** 정확도가 어떻게 달라지는지 비교했다.

### 준비

| 항목 | 내용 |
|---|---|
| 데이터 | 150종, 학습 70% / 검증 10% / 테스트 20%로 분할 (학습 4,703장, 테스트 1,502장) |
| 전처리 | 240×240 크기 조정, 정규화. 학습 데이터에만 무작위 회전(30°)과 좌우 뒤집기를 넣어 데이터를 늘림 |
| Model_0 | 합성곱 3층(채널 6 → 12 → 24, 각 층 뒤 ReLU + 최대 풀링) + 완전연결 3층(512 → 256 → 150). 출력은 log-softmax |
| 학습 | NLLLoss, Adam(학습률 0.001), 배치 256, 50 에폭 |
| 환경 | Intel i7-9700K, RTX 2080 Ti |

![학습 배치 예시](assets/dl-pokemon-batch.jpg){ width="380" }
*학습 배치 예시. 무작위 회전과 좌우 뒤집기가 적용되어 있다.*

![종별 학습 이미지 수](assets/dl-pokemon-classes.png)
*종별 학습 이미지 수. 대부분 25–40장으로, 종마다 데이터가 적다.*

Model_0의 테스트 정확도는 **55.4%**다. 이후 모든 실험은 이 모델에서 출발한다.

### 실험 결과

| 실험 | 바꾼 것 | 테스트 정확도 |
|---|---|---|
| Model_0 (기준) | | 55.4% |
| Xavier 초기화 | 합성곱·완전연결 층 가중치를 Xavier uniform으로 초기화 | 54.7% |
| L2 정규화 | Adam에 weight decay 0.01 | 48.5% |
| 드롭아웃 | 완전연결 층에 드롭아웃 0.5 | 53.0% |
| 배치 정규화 | 각 합성곱·완전연결 층 뒤에 BatchNorm | **56.0%** |
| SGD | Adam 대신 SGD(학습률 0.001) | 3.0% |
| SGD + 모멘텀 | SGD에 모멘텀 0.9 | 44.3% |
| StepLR | 10 에폭마다 학습률 × 0.1 | 49.3% |
| MultiStepLR | 40, 60, 80 에폭에서 학습률 × 0.1 | 52.8% |
| ExponentialLR | 매 에폭 학습률 × 0.99 | 51.9% |
| Dilated conv | 첫 합성곱에 dilation 3 | 52.7% |
| Two-branch | 같은 구조의 합성곱 가지 두 개를 나란히 두고 출력을 합침 | 54.9% |
| 불안정한 신경망 | 모델 출력을 log 없이 softmax로 두고 NLLLoss를 그대로 씀 | 1.1% (손실 inf) |
| 가변 크기 입력 | 마지막 풀링을 AdaptiveAvgPool(30×30)로 바꿔 어떤 크기의 입력도 받게 함 | 51.4% (검증) |
| **사전학습 ResNet-34** | ImageNet으로 학습된 ResNet-34를 가져와 다시 학습 | **86.0%** (검증) |

이 밖에 첫 합성곱을 7×7로 키우고 1×1 합성곱을 더해 계산량을 줄이는 구조, 중간에 bilinear 업샘플링(56×56)을 넣는 구조도 만들었다.

### 결과에서 본 것

- **처음부터 학습한 모델은 기법을 바꿔도 55% 근처에서 크게 달라지지 않았다.** 배치 정규화만 조금 올랐고, 나머지는 비슷하거나 떨어졌다. 종마다 학습 사진이 30장 정도뿐인 작은 데이터셋에서 작은 모델로는 기법만 바꿔서 얻을 수 있는 차이가 크지 않았다.
- **사전학습 ResNet-34만 86%로 크게 앞섰다.** 큰 데이터셋에서 이미 배운 특징을 가져다 쓰는 전이학습의 효과가, 작은 모델에 어떤 기법을 더하는 것보다 훨씬 컸다.
- **옵티마이저 차이가 가장 극적이었다.** 같은 학습률의 순수 SGD는 50 에폭 동안 거의 학습하지 못했고(3%), 모멘텀만 더해도 44%까지 올라갔다. 이전 기울기를 누적해 한 방향으로 꾸준히 움직이게 하는 모멘텀의 효과가 그대로 보였다.
- **정규화도 세기가 중요하다.** weight decay 0.01은 이 모델에는 너무 강해서 오히려 정확도가 7%p 떨어졌다.
- **softmax 뒤에 log를 빼먹으면 학습이 무너진다.** NLLLoss는 log 확률을 입력으로 기대하는데 확률을 그대로 넣으니 손실이 음수가 되고, 테스트 손실은 inf가 되어 정확도가 무작위 수준(1/150)으로 떨어졌다. 그래서 log-softmax를 한 번에 계산하거나 CrossEntropyLoss를 쓴다.

### 시각화: CAM과 Grad-CAM

ResNet-34가 이미지의 어디를 보고 판단했는지 히트맵으로 확인했다.

- **CAM:** ResNet 마지막의 전역 평균 풀링 덕분에, 예측한 클래스의 완전연결 층 가중치로 마지막 특징 맵들을 가중합하면 클래스별 히트맵이 나온다.
- **Grad-CAM:** 예측 점수를 특징 맵으로 미분한 기울기를 가중치로 쓴다. 전역 평균 풀링에 붙은 층뿐 아니라 원하는 어떤 층이든 시각화할 수 있다. 히트맵을 원본 이미지에 겹쳐 모델이 주목한 영역을 확인했다.
