!!! summary "이 수업은"
    2021년 1학기에 들은 대학교 수업이다. PLC의 동작 원리와 래더 다이어그램을 배우고, 미쓰비시 **GX Works**로 로직을 짜서 **공압 실린더**로 작은 고무 원판을 목적지까지 옮기는 이송 공정을 만들었다. 같은 공정을 **시간 제어**와 **센서 제어** 두 방식으로 짰다.

## 한 일

공압 실린더들을 순서대로 움직여 고무 원판을 밀고 옮겨 목적지까지 보낸다. 다음 동작으로 넘어가는 조건을 두 가지로 바꿔 가며 같은 공정을 구현했다.

| 방식 | 다음 동작으로 넘어가는 조건 |
|---|---|
| 시간 제어 | 타이머로 정한 시간이 지나면 |
| 센서 제어 | 실린더 끝단 센서나 물체 감지 센서 신호가 들어오면 |

## 배운 내용

### PLC가 도는 방식

PLC(Programmable Logic Controller)는 공장 설비를 제어하는 산업용 컴퓨터다. 예전에 릴레이를 전선으로 이어 만들던 제어 회로를 프로그램으로 바꾼 것이라, 배선을 다시 하지 않고 로직만 고쳐 동작을 바꿀 수 있다.

PLC는 다음 세 단계를 아주 빠르게 계속 반복한다(**스캔**).

1. 버튼과 센서 같은 **입력** 상태를 한꺼번에 읽는다.
2. 읽은 값으로 **프로그램**을 위에서 아래로 한 번 실행한다.
3. 결과를 솔레노이드 밸브나 램프 같은 **출력**으로 내보낸다.

### 래더 다이어그램

릴레이 회로도처럼 생긴 그림으로 로직을 짠다. 왼쪽 세로선에서 오른쪽으로 신호가 흐른다고 보고, 조건(접점)이 맞으면 출력(코일)이 켜진다.

| 요소 | 뜻 |
|---|---|
| a접점 | 입력이 켜지면 닫힘(신호 통과) |
| b접점 | 입력이 켜지면 열림(신호 차단) |
| 코일 | 앞의 조건이 맞으면 켜지는 출력이나 내부 릴레이 |
| 자기유지 | 버튼을 뗀 뒤에도 출력이 켜진 채로 있게 자기 접점으로 다시 신호를 이어 주는 회로. 정지 버튼(b접점)으로 끊는다 |
| 타이머 | 조건이 켜진 뒤 정한 시간이 지나면 접점이 바뀜 |
| 카운터 | 신호가 들어온 횟수를 세서 정한 수가 되면 접점이 바뀜 |

### 시간 제어와 센서 제어

| | 시간 제어 | 센서 제어 |
|---|---|---|
| 방식 | "실린더가 이 정도면 끝까지 갔겠지" 하는 시간을 타이머로 정함 | 실린더가 끝까지 갔다는 센서 신호를 확인하고 넘어감 |
| 장점 | 센서가 없어도 되고 로직이 간단하다 | 실제로 동작이 끝난 것을 확인하므로 확실하다 |
| 단점 | 공기 압력이나 부하가 바뀌어 실린더 속도가 달라지면 타이밍이 어긋난다 | 센서 배선과 설치가 필요하다 |

실제 설비에서는 센서로 동작 완료를 확인하고, 정해진 시간 안에 신호가 안 오면 고장으로 판단하는 데 타이머를 함께 쓴다.

### 순차 제어 설계

[유공압실습](03-pneumatics.md)에서 배운 순차 제어를 PLC로 옮긴다. 공정을 단계로 나누고, 단계마다 "어떤 출력을 켜는지"와 "어떤 조건이 되면 다음 단계로 가는지"를 정한 뒤 래더로 옮긴다. 한 단계가 켜지면 앞 단계를 끄도록 짜서 두 단계가 동시에 켜지지 않게 한다.
