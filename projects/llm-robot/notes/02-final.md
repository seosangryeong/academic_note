!!! summary "한 줄 요약"
    무중력 우주선 내부를 Isaac Sim으로 만들고, 레일 위를 오가는 **Franka Panda 로봇팔**이 **"버튼 눌러줘"**, **"레버 내려줘"** 같은 자연어 명령을 받아 움직이게 했다. LLM은 Function Calling으로 레일 이동, 회전, 팔 동작 함수를 고르고, 팔의 역기구학은 ROS 2의 **MoveIt 2**가 풀어 Isaac Sim에 관절 명령을 보낸다. 위치가 고정된 버튼과 레버는 매번 성공했다.

## 목표와 시나리오

**목표:** 중력이 없는 우주선 안에서 사람이 직접 움직이는 것보다 빠르고 정확하게, 자연어 명령만으로 로봇이 일하게 한다.

| 시나리오 | 동작 |
|---|---|
| 버튼 누르기 | 로봇팔로 벽의 버튼을 누름 |
| 레버 내리기 | 로봇팔로 레버를 위에서 아래로 내림 |
| 복귀 | 일을 마친 뒤 처음 위치로 돌아옴 |

## 로봇 구조

![레일 위의 Panda 로봇팔](assets/final-robot.jpg)
*바닥의 레일(직선 관절)과 기둥(회전 관절) 위에 얹은 Franka Panda.*

| 부분 | 내용 |
|---|---|
| 로봇팔 | Franka Emika Panda: 사람 팔과 같은 7 자유도 |
| 직선 관절 (Prismatic) | 레일을 따라 로봇 전체를 앞뒤로 이동 |
| 회전 관절 (Revolute) | 기둥을 돌려 팔이 향하는 방향을 바꿈. 바닥 가까운 물체에도 팔이 닿게 함 |

무중력 상태에서는 다리나 바퀴로 바닥을 밀어 움직일 수 없어서, 우주선에 고정된 레일을 따라 움직이는 구조로 했다.

## 시스템 구성

| 단계 | 하는 일 |
|---|---|
| 1. 사용자 | 자연어 명령 입력. 예: "로봇을 5 m 이동한 후 시계방향 90도 회전하고 로봇팔을 (0.3, 0.2, 0.3)으로 이동해줘" |
| 2. OpenAI API | 명령을 함수 호출로 바꿈. 예: [레일 5 m 이동 → 회전 관절 시계방향 90도] + [엔드이펙터를 (0.3, 0.2, 0.3)으로] |
| 3. 제어 노드 (ROS 2) | 레일·회전 관절은 목표값(예: `[5.0, −π/2]`)을 바로 보내고, 팔 목표 위치는 MoveIt 2에 넘김 |
| 4. MoveIt 2 | 목표 위치까지의 궤적을 만들고 역기구학으로 관절 각도를 계산 |
| 5. Isaac Sim | 관절 명령대로 움직이고, 현재 관절 상태를 다시 내보냄 |

### Isaac Sim – MoveIt 2 동기화

![MoveIt 2와 Isaac Sim 동기화 화면](assets/final-moveit.jpg)
*왼쪽이 MoveIt 2(RViz), 오른쪽이 Isaac Sim. 같은 자세를 유지한다.*

Isaac Sim에서 각 관절의 현재 위치를 받아 MoveIt 2의 로봇 상태를 맞춘다. MoveIt 2는 그 상태에서 목표까지 궤적을 만들고, 계산한 관절 값을 Isaac Sim에 관절 명령으로 보낸다. 시뮬레이터와 계획기가 같은 자세를 보고 있어야 계획한 궤적대로 움직인다.

## 핵심 기법

### Function Calling

| 함수 | 동작 |
|---|---|
| 레일 이동 | 직선 관절을 지정한 거리만큼 이동 (예: "레일 −2 m 이동", "레일 4 m 이동") |
| 회전 | 회전 관절을 지정한 방향과 각도로 회전 (예: "시계방향 30도 회전", "반시계방향 90도 회전") |
| 팔 조작 | 엔드이펙터를 지정한 좌표로 이동 |

### 연속 동작

명령 하나로 여러 함수를 이어서 실행한다.

| 명령 | 실행되는 동작 |
|---|---|
| "버튼 눌러줘" | 레일 7.5 m 이동(버튼과 같은 위치) → 기둥을 시계방향 π/3 회전(버튼 쪽) → 팔을 뻗어 버튼 누르기 |
| "레버 내려줘" | 레일 8.4 m 이동(팔이 레버에 닿는 거리) → 팔로 레버를 위에서 아래로 내리기 |

## 결과

- 무중력 상태이고 버튼·레버처럼 우주선에 고정된 물체는 월드 좌표가 바뀌지 않으므로, 두 동작 모두 **매번 성공**했다.
- 처음 상태(레일 0 m, 회전 0 rad)로 돌아가라는 명령은 **문장 표현에 따라 LLM이 알아듣지 못했다.**

| 표현 | 결과 |
|---|---|
| 원점으로 / 초기위치로 / 원상태로 / 원래 위치로 | 실패 |
| 원래상태로 / 홈으로 | 성공 |

## 한계와 개선

| 한계 | 개선 방향 |
|---|---|
| 정해진 위치의 물체만 다룰 수 있다 | 카메라나 라이다로 물체를 인식한 뒤 제어 |
| 미리 정해 둔 관절 각도로 팔을 움직여서, 경로에 장애물이 있으면 걸린다 | 센서로 장애물을 인식하고 A*, RRT 같은 경로 계획으로 피해 가기 |
| 물체를 집어 옮기는 동작이 없다 | 물체 인식 후 그리퍼로 Pick and Place. 무중력에서는 작은 힘에도 물체가 계속 밀려가므로 확실하게 잡는 파지 방법이 필요 |
