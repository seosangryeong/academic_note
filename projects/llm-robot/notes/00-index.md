## 주차 과제 {#homework}

### 거북이로 이름 쓰기

ColabTurtlePlus의 거북이 그래픽을 GPT-4o의 Function Calling으로 움직였다. 앞으로/뒤로 가기(`move_turtle`), 왼쪽/오른쪽 돌기(`turn_turtle`), 펜 올리기/내리기(`pen_control`) 세 함수를 도구로 주고, 그 위에 한글 자모(ㅅ, ㅓ, ㅏ, ㄹ, ㅕ, 받침 ㅇ)를 그리는 함수를 만들어 이름 "서상령"을 썼다.

### Function Calling으로 과일 가격 계산

과일 이름을 받아 가격을 돌려주는 `get_fruit_price` 함수를 도구로 주고 "사과 3개와 배 1개는 얼마야?"라고 물었다. 모델이 함수를 불러 사과(1,000원)와 배(800원) 가격을 받은 뒤, 두 번째 호출에서 이를 합쳐 **3,800원**이라고 답했다.

??? 원리: Function Calling이 도는 순서
    1. 함수 이름, 설명, 인자 형식(JSON 스키마)을 `tools`로 모델에 함께 보낸다.
    2. 모델은 바로 답하거나, "이 함수를 이 인자로 불러 달라"는 요청(`tool_calls`)을 돌려준다.
    3. 내 코드가 그 함수를 실제로 실행하고, 결과를 `tool` 역할 메시지로 대화에 붙인다.
    4. 모델을 한 번 더 부르면 함수 결과를 보고 최종 답을 만든다.

    모델은 함수를 직접 실행하지 않고 고르기만 한다. 그래서 로봇에 쓸 때도 위험한 동작은 함수 쪽에서 막을 수 있다.
