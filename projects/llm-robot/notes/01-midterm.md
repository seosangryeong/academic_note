!!! summary "한 줄 요약"
    Webots 시뮬레이터에서 바퀴 달린 로봇이 **"탐색하다가 캔을 발견하면 캔을 잡아줘"** 같은 자연어 명령을 받아, 장애물을 피하며 돌아다니다 카메라로 캔을 찾으면 다가가 집어 올리게 했다. 명령은 OpenAI API의 Function Calling으로 `move_robot`, `pick_can`, `drop_can` 세 함수 중 하나로 바뀐다. 캔 집기와 옮긴 뒤 내려놓기를 각각 25번씩 시험해 모두 성공했다.

## 시나리오

| 단계 | 로봇이 하는 일 |
|---|---|
| 이해 | 자연어 명령을 읽고 "캔 탐색"을 시작 |
| 탐색·회피 | 거리 센서로 장애물을 피하며 맵을 돌아다님 |
| 발견·접근 | 카메라에 캔이 보이면 캔 쪽으로 다가감 |
| 수행 | 그리퍼로 캔을 집어 들어 올리고, LED를 켜서 잡은 상태를 표시 |

## 로봇 모델

![로봇 모델](assets/mid-robot.jpg){ width="420" }
*Webots에서 만든 로봇. 앞의 노란 판 두 개가 그리퍼, 위의 파란 상자가 카메라.*

| 부품 | 역할 |
|---|---|
| 바퀴 모터 2개 (좌·우) | 이동. 두 바퀴 속도 차이로 회전 |
| 그리퍼 리니어 모터 2개 (좌·우) | 캔 잡기 |
| 수직 리니어 모터 | 잡은 캔 들어 올리기 |
| 카메라 | 캔 인식 |
| 거리 센서 3개 (가운데·왼쪽·오른쪽) | 장애물 감지 |
| LED | 잡은 상태 표시 |

## 시스템 구성

| 단계 | 하는 일 |
|---|---|
| 1. 사용자 | 웹 화면(Robot Window)에 자연어 명령 입력. 앞/뒤/좌/우 버튼도 있음 |
| 2. 로봇 컨트롤러 | 명령을 OpenAI API에 보내 어떤 함수를 부를지 받아 옴 |
| 3. 함수 실행 | 고른 함수대로 바퀴·그리퍼·LED 모터를 움직이고, 카메라와 거리 센서 값을 읽음 |
| 4. 상태 표시 | 현재 상태("캔 탐색 중", "드롭 대기" 등)를 웹 화면에 다시 보냄 |

![Webots 시뮬레이션 화면](assets/mid-webots.jpg)
*왼쪽이 Webots 맵(바위 장애물과 캔), 오른쪽이 명령을 넣는 웹 화면. 왼쪽 위 작은 창이 로봇 카메라 화면이다.*

## 핵심 기법

### Function Calling

| 함수 | 인자 | 동작 |
|---|---|---|
| `move_robot` | 방향, 속도, 시간 | 정한 방향으로 정한 시간만큼 이동 |
| `pick_can` | | 캔 탐색 → 장애물 회피 → 접근 → 잡기 → 들기를 이어서 수행 |
| `drop_can` | | 들고 있던 캔을 내려놓음 |

"캔을 집어 → 뒤로 3초간 이동 후 캔 내려놔 → 뒤로 가"처럼 여러 단계 명령도 함수 호출 여러 개로 나눠 차례로 실행한다.

### 조건부 센서 사용

- 카메라에 캔이 **안 보이면** 거리 센서를 켜고 장애물을 피하며 탐색한다.
- 캔이 **보이면** 거리 센서를 무시하고 캔으로 곧장 다가간다. 캔도 거리 센서에는 장애물로 잡히기 때문에, 이렇게 하지 않으면 캔 앞에서 피해 버린다.

### 장애물 회피

- 가운데 센서에 장애물이 잡히면 왼쪽·오른쪽 센서 중 **더 멀리 비어 있는 쪽**으로 돈다.
- 로봇이 한동안 움직이지 않으면(구석에 끼임) **뒤로 물러난 뒤 돌아서** 빠져나온다.

## 결과

| 시험 | 성공률 |
|---|---|
| 카메라에 캔이 보이는 상태에서 집기 | 100% (25/25) |
| 캔이 안 보이는 상태에서 탐색 후 집기 | 100% (25/25) |
| 집은 채로 후진한 뒤 내려놓기 | 100% (25/25) |
| 집은 채로 전진한 뒤 내려놓기 | 100% (25/25) |
| 집은 채로 회전한 뒤 내려놓기 | 100% (25/25) |

## 한계와 개선

| 한계 | 개선 방향 |
|---|---|
| 장애물이 적고 모양이 단순했다. 의자나 책상처럼 아래가 뚫린 장애물은 거리 센서로 잡기 어렵다 | 라이다로 감지 |
| 맵을 만들지 않아서, 캔을 원하는 위치에 가져다 놓을 수 없다 | GPS나 라이다로 지도를 만든 뒤 원하는 위치에 내려놓기 |
| 이미 지나간 곳을 다시 탐색할 수 있다 | SLAM 등으로 탐색한 영역을 기억 |
